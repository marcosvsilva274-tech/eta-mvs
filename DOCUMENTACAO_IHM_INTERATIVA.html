1. Visão Geral da IHM Interativa

O que é uma IHM?

IHM = Interface Humana-Máquina. É uma tela que permite ao operador visualizar e controlar um sistema (neste caso, uma Estação de Tratamento de Água).

Características da Nossa IHM

  • 3 Painéis Principais: Controle de motores, fluxo de processo e alarmes
  • Interatividade: Botões para ligar/desligar bombas e válvulas
  • Visualização em Tempo Real: Sensores, níveis de tanques e eventos
  • Feedback Visual: Animações, cores dinâmicas e mudanças instantâneas
  • Log de Eventos: Histórico de todas as operações
  • Design Profissional: Layout moderno em 3 colunas

3. Estrutura de Dados (Variáveis Reativas)

Todos os dados da IHM são gerenciados com a função ref do Vue, que torna os dados reativos:

3.1 - Bombas (Motores)

const bombas = [ { id: 1, nome: 'Bomba de Alimentação', ligada: true, // Estado: ligada ou desligada potencia: '7.5 kW', // Especificação técnica rpm: 1800 // Rotação por minuto }, { id: 2, nome: 'Bomba de Recirculação', ligada: true, potencia: '5.5 kW', rpm: 1500 }, // ... mais 2 bombas ]

Explicação:

  • id: Identificador único para renderização com v-for
  • nome: Descrição da bomba
  • ligada: TRUE = motor ligado | FALSE = desligado (alterado por clique)
  • potencia: Potência da bomba (informativo)
  • rpm: Rotação do motor (informativo)

3.2 - Sensores (Indicadores)

const sensores = [ { label: 'Vazão Entrada', value: '18.4', // Valor que muda unit: 'L/s', // Unidade de medida min: 15, // Valor mínimo aceitável max: 25 // Valor máximo aceitável }, { label: 'pH', value: '7.2', unit: 'pH', min: 6.5, max: 8.5 }, { label: 'Temperatura', value: '22', unit: '°C', min: 10, max: 35 }, { label: 'Turbidez', value: '1.1', unit: 'NTU', min: 0, max: 5 } ]

Explicação:

  • label: Nome do sensor
  • value: Valor atual (muda quando bombas são acionadas)
  • unit: Unidade física (L/s, pH, °C, etc)
  • min/max: Faixa de operação segura

3.3 - Tanques

const tanques = [ { id: 1, nome: 'Tanque Água Bruta', nivel: 85 }, { id: 2, nome: 'Tanque Coagulação', nivel: 72 }, { id: 3, nome: 'Tanque Flotação', nivel: 68 }, { id: 4, nome: 'Tanque Desinfecção', nivel: 90 }, { id: 5, nome: 'Tanque Final', nivel: 95 } ]

Explicação:

  • id: Identificador para v-for
  • nome: Nome do tanque
  • nivel: Percentual de preenchimento (0-100%)

3.4 - Válvulas

const valvulas = [ { id: 1, nome: 'Válvula Entrada', aberta: true }, { id: 2, nome: 'Válvula Descarga Lodos', aberta: false }, { id: 3, nome: 'Válvula Saída', aberta: true } ]

Explicação:

  • aberta: TRUE = aberta | FALSE = fechada

3.5 - Alarmes

const alarmes = [ { id: 1, titulo: 'Turbidez elevada', detalhe: 'Ajuste de filtro pendente', nivel: 'Aviso', // Afeta cor: aviso, normal, ok ativo: true }, // ... mais alarmes ]

Explicação:

  • nivel: Define a cor do alerta (Aviso=amarelo, Normal=cinza, OK=verde)
  • ativo: Se está sendo exibido

3.6 - Eventos (Log do Sistema)

const eventos = ref([ { hora: '16:45', msg: 'Bomba 1 acionada' }, { hora: '16:40', msg: 'Válvula de saída aberta' }, { hora: '16:35', msg: 'Sistema iniciado com sucesso' }, ])

Explicação:

  • ref([]): Array que será modificado durante a execução
  • hora: Timestamp do evento
  • msg: Descrição do que aconteceu
  • unshift(): Adiciona novo evento no topo da lista

5. Funções Interativas

5.1 - toggleBomba(bomba)

const toggleBomba = (bomba) => { // 1. Inverte o estado da bomba bomba.ligada = !bomba.ligada // 2. Simula mudança na vazão if (bomba.ligada) { // Se ligada: aumenta a vazão sensores[0].value = (parseFloat(sensores[0].value) + Math.random() * 2).toFixed(1) // Registra evento eventos.value.unshift({ hora: new Date().toLocaleTimeString('pt-BR'), msg: `${bomba.nome} LIGADA` }) } else { // Se desligada: diminui a vazão sensores[0].value = (parseFloat(sensores[0].value) - Math.random() * 1).toFixed(1) // Registra evento eventos.value.unshift({ hora: new Date().toLocaleTimeString('pt-BR'), msg: `${bomba.nome} DESLIGADA` }) } }

Como funciona:

  1. Usuário clica no botão LIGAR/DESLIGAR da bomba
  2. A função toggleBomba é chamada com a bomba como argumento
  3. O estado bomba.ligada é invertido (true ↔ false)
  4. O valor da vazão (sensores[0].value) é atualizado dinamicamente
  5. Um novo evento é adicionado ao topo do array eventos
  6. Vue detecta a mudança e re-renderiza automaticamente
  7. O usuário vê:
    • Badge mudando cor
    • Animação do motor mudando
    • Valor da vazão mudando
    • Novo evento no log

5.2 - toggleValvula(valvula)

const toggleValvula = (valvula) => { // Inverte o estado da válvula valvula.aberta = !valvula.aberta // Registra o evento com a hora atual eventos.value.unshift({ hora: new Date().toLocaleTimeString('pt-BR'), msg: `${valvula.nome} ${valvula.aberta ? 'ABERTA' : 'FECHADA'}` }) }

Diferença:

Mais simples que toggleBomba. Apenas inverte o estado e registra o evento. Não modifica sensores.

5.3 - corNivel(nivel)

const corNivel = (nivel) => { if (nivel < 30) return '#ff6b6b' // Vermelho (baixo) if (nivel < 60) return '#ffd93d' // Amarelo (médio) return '#6bcf7f' // Verde (alto) }

Explicação:

Função que retorna uma cor hexadecimal baseada no nível do tanque:

  • < 30%: Vermelho (perigo - nível baixo)
  • 30%-60%: Amarelo (atenção - nível médio)
  • > 60%: Verde (seguro - nível alto)

Usada no binding CSS: :style="{ backgroundColor: corNivel(tanque.nivel) }"

5.4 - fazerLogout()

const fazerLogout = () => { usuarioLogado.value = null localStorage.removeItem('usuario_logado') }

Explicação:

  • Limpa a variável reativa usuarioLogado
  • Remove do localStorage
  • Vue detecta a mudança e renderiza o LoginForm novamente

6. Estilos CSS e Design

6.1 - Layout Grid 3 Colunas

.ihm-content { display: grid; grid-template-columns: 1fr 2fr 1fr; /* 3 colunas: 1 : 2 : 1 */ gap: 20px; padding: 20px; overflow-y: auto; }

Explicação:

  • grid-template-columns: Define 3 colunas
  • 1fr: Coluna flexível (fração do espaço)
  • 2fr: Coluna do meio com o dobro de tamanho
  • gap: 20px: Espaço entre colunas

6.2 - Cards das Bombas

.bomba-card { background: linear-gradient(135deg, #f5f7fa 0%, #c3cfe2 100%); border: 2px solid #ddd; border-radius: 10px; padding: 15px; transition: all 0.3s ease; } .bomba-card.ativo { background: linear-gradient(135deg, #84fab0 0%, #8fd3f4 100%); border-color: #00b894; box-shadow: 0 0 15px rgba(0, 184, 148, 0.3); }

Como funciona:

  • Padrão: Gradiente cinza quando bomba está desligada
  • .ativo: Classe CSS que é aplicada quando bomba.ligada === true
  • linear-gradient: Efeito de gradiente suave
  • box-shadow: Halo verde de brilho quando ativa
  • transition: Animação suave de 0.3s entre estados

No Template Vue:

<div class="bomba-card" :class="{ ativo: bomba.ligada }"> <!-- :class vincula a classe 'ativo' à propriedade bomba.ligada --> </div>

6.3 - Animação do Motor SVG

.motor-icon { animation: rotate 2s linear infinite; opacity: 0.3; } .motor-icon.spinning { opacity: 1; animation: rotate 1s linear infinite; } @keyframes rotate { from { transform: rotate(0deg); } to { transform: rotate(360deg); } }

Como funciona:

  • Padrão: Rotação lenta (2s) com opacidade baixa (0.3)
  • .spinning: Quando bomba está ligada, gira mais rápido (1s) e fica visível (opacity: 1)
  • @keyframes: Define a animação de rotação 360°
  • linear: Velocidade constante
  • infinite: Gira continuamente

6.4 - Visualização dos Tanques

.tanque-container { height: 120px; background: #f0f0f0; border: 2px solid #999; overflow: hidden; /* Esconde o que sai da borda */ } .tanque-nivel { height: 0%; /* Será mudado dinamicamente */ transition: height 0.3s ease; background-color: /* cor calculada por corNivel() */ }

Como funciona:

  • Cria um container que simula um tanque
  • Uma div interna (tanque-nivel) representa a água
  • A altura é definida dinamicamente: :style="{ height: tanque.nivel + '%' }"
  • Quando tanque.nivel muda, a altura também muda com transição suave
  • A cor é dinâmica baseada em corNivel()

No Template:

<div class="tanque-nivel" :style="{ height: tanque.nivel + '%', backgroundColor: corNivel(tanque.nivel) }"> </div>

7. Fluxo de Interação

Exemplo: Usuário clica em "LIGAR" Bomba 1

1️⃣ Evento de Click

Usuário clica no botão com @click="toggleBomba(bomba)"

2️⃣ Vue Detecta o Evento

Vue captura o evento de click e chama a função toggleBomba(bomba)

3️⃣ Função Executa

bomba.ligada = !bomba.ligada // true vira false ou vice-versa sensores[0].value = ... // Muda o valor da vazão eventos.value.unshift(...) // Adiciona novo evento

4️⃣ Vue Detecta Mudanças

Como estamos usando ref(), Vue sabe que os dados mudaram e re-renderiza o componente automaticamente

5️⃣ Template é Re-renderizado

Vue re-executa o template com os novos valores:

  • Badge muda: {{ bomba.ligada ? 'LIGADA' : 'DESLIGADA' }}
  • Classe CSS muda: :class="{ ativo: bomba.ligada }"
  • Animação SVG muda: :class="{ spinning: bomba.ligada }"
  • Valor sensor atualiza: {{ sensores[0].value }}
  • Novo evento aparece no topo do log

6️⃣ Navegador Renderiza

O navegador exibe todas as mudanças visuais instantaneamente

7️⃣ Usuário Vê Resultado

  • ✅ Card ficou verde com brilho
  • ✅ Badge mostra "LIGADA"
  • ✅ Motor SVG gira rápido
  • ✅ Vazão aumentou
  • ✅ Novo evento no log com timestamp

10. Design Responsivo

Desktop (> 1400px)

.ihm-content { grid-template-columns: 1fr 2fr 1fr; /* 3 colunas lado a lado */ gap: 20px; } .tanques-grid { grid-template-columns: repeat(5, 1fr); /* 5 tanques em linha */ } .sensores-display { grid-template-columns: repeat(2, 1fr); /* 2x2 sensores */ }

Tablet (768px - 1400px)

@media (max-width: 1400px) { .ihm-content { grid-template-columns: 1fr; /* 1 coluna (tudo empilhado) */ } .tanques-grid { grid-template-columns: repeat(3, 1fr); /* 3 tanques por linha */ } }

Mobile (< 768px)

@media (max-width: 768px) { .bombas-grid { grid-template-columns: repeat(2, 1fr); /* 2 bombas por linha */ } .tanques-grid { grid-template-columns: repeat(2, 1fr); /* 2 tanques por linha */ } .valvulas-grid { grid-template-columns: 1fr; /* 1 válvula por linha */ } }

Resumo de Como a IHM Foi Desenvolvida

✅ Estrutura de Dados
