1. Introdução do Projeto

O que é o Supervisório ETA?

O Supervisório ETA é um sistema web de monitoramento em tempo real de uma Estação de Tratamento de Água (ETA). A aplicação foi desenvolvida utilizando Vue.js 3 (framework JavaScript progressivo) e Vite (ferramenta de build rápida e moderna).

Objetivo do Sistema

Fornecer uma interface visual intuitiva para monitores os principais parâmetros de qualidade da água, acompanhar os processos de tratamento, gerenciar alarmes e controlar equipamentos da estação.

Principais Funcionalidades

  • Autenticação: Sistema de login com múltiplos usuários
  • Dashboard Dinâmico: Visualização de dados em tempo real
  • Indicadores: Vazão, pH, Nível e Turbidez
  • Processos: Acompanhamento dos 5 estágios de tratamento
  • Alarmes: Sistema de alertas para situações anormais
  • Controle: Interface para comandar equipamentos
  • Persistência: Dados salvos no localStorage do navegador

5. Como Funciona o Fluxo da Aplicação

O fluxo de execução da aplicação segue este padrão:

Fluxo de Inicialização

  1. index.html: Navegador carrega o arquivo HTML principal
  2. main.js: Ponto de entrada - cria e monta a aplicação Vue
  3. App.vue: Componente raiz carrega
  4. onMounted(): Hook verifica se há usuário salvo no localStorage
  5. Renderização Condicional:
    • Se NÃO houver usuário → mostra LoginForm
    • Se houver usuário → mostra Dashboard

Fluxo de Login

  1. Usuário acessa a página
  2. Componente LoginForm é exibido
  3. Usuário digita suas credenciais
  4. Ao clicar "Entrar" ou pressionar Enter:
  5. Sistema valida as credenciais com o objeto credenciaisValidas
  6. Se válidas:
    • Salva usuário no localStorage
    • Emite evento 'login' para App.vue
    • App.vue atualiza usuarioLogado
    • Dashboard é renderizado
  7. Se inválidas: exibe mensagem de erro

Fluxo de Visualização do Dashboard

  1. Dashboard é exibido com:
    • Cabeçalho (header) com nome do usuário
    • Painel hero com título e métrica de eficiência
    • Cards de indicadores (Vazão, pH, Nível, Turbidez)
    • Barras de progresso dos processos
    • Painel de alarmes
    • Painel de controle de equipamentos
  2. Dados são renderizados dinamicamente com v-for
  3. Usuário pode clicar em "Sair" para fazer logout
  4. Logout limpa localStorage e volta para tela de login
